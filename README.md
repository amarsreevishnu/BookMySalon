# BookMySalon

BookMySalon is a salon booking platform that allows customers to discover salons, view services, select available time slots, and book appointments.

## 🚀 Features

- Customer registration and login
- Salon browsing
- Salon and branch management
- Service management
- Worker management
- Appointment booking
- Time-slot management
- Online payment
- Owner dashboard
- Worker dashboard
- Admin dashboard
- Role-based authentication

## 🛠️ Technologies

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- React
- Vite
- Redux Toolkit
- Tailwind CSS

### Other
- JWT Authentication
- Git & GitHub
